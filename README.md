# Интернет-магазин для мессенджера Макс

Полнофункциональный интернет-магазин в виде Telegram-бота для российской платформы Макс.

## 🚀 Возможности

### Для покупателей:
- 🛍️ Просмотр каталога товаров по категориям
- 🔍 Поиск товаров по названию
- 🛒 Управление корзиной (добавление, изменение количества, удаление)
- ❤️ Добавление товаров в избранное
- ✅ Оформление заказов с выбором способа оплаты
- 📱 Запрос контактных данных через встроенные кнопки Макса

### Для администраторов:
- 👥 Управление товарами (добавление, редактирование, удаление)
- 📊 Просмотр статистики продаж
- 🛠️ Управление заказами и их статусами
- 💬 Получение уведомлений о новых заказах

## 🛠️ Технологии

- **PHP 7.4+** - основной язык разработки
- **MySQL** - база данных для хранения товаров, заказов и пользователей
- **Max Bot API** - для интеграции с мессенджером Макс
- **CURL** - для HTTP запросов к API

## 📋 Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Сервер для размещения вебхука (Apache/Nginx)
- SSL сертификат для HTTPS соединения

## ⚙️ Установка и настройка

### 1. Создание базы данных

```sql
-- Создайте базу данных
CREATE DATABASE max_shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Выполните скрипт из файла database.sql
mysql -u username -p max_shop < database.sql
```

### 2. Настройка конфигурации

Отредактируйте файл `config.php`:

```php
$config = [
    'bot' => [
        'token' => 'ВАШ_ТОКЕН_БОТА', // Получите от @MasterBot в Максе
        'username' => 'your_bot_username',
        'name' => 'QuickShop Bot'
    ],

    'database' => [
        'host' => 'localhost',
        'username' => 'ВАШ_ЛОГИН_БД',
        'password' => 'ВАШ_ПАРОЛЬ_БД',
        'database' => 'max_shop',
        'charset' => 'utf8mb4'
    ],

    'webhook' => [
        'url' => 'https://yourdomain.com/webhook.php',
        'secret' => 'your_webhook_secret'
    ],

    'admin' => [
        'password' => 'ВАШ_ПАРОЛЬ_АДМИНА',
        'chat_id' => 'ВАШ_CHAT_ID'
    ]
];
```

### 3. Получение токена бота

1. Напишите боту @MasterBot в Максе
2. Создайте нового бота командой `/newbot`
3. Следуйте инструкциям и получите токен
4. Вставьте токен в конфигурацию

### 4. Настройка вебхука

```bash
# Настройка вебхука
php setup_webhook.php

# Или вручную через API:
curl -X POST "https://botapi.max.ru/subscriptions?access_token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourdomain.com/webhook.php",
    "secret": "your_webhook_secret"
  }'
```

## 🚀 Запуск бота

### Способ 1: Вебхук (рекомендуется для продакшена)

1. Разместите файлы на сервере с HTTPS
2. Настройте вебхук (см. выше)
3. Бот будет автоматически получать обновления

### Способ 2: Long Polling (для тестирования)

```bash
php bot.php
```

Бот будет работать в консоли и получать обновления через long polling.

## 🛒 Использование

### Для покупателей:

1. **Запуск бота**: Отправьте `/start`
2. **Каталог**: Нажмите "🛍️ Каталог" для просмотра категорий
3. **Товары**: Выберите категорию и просматривайте товары
4. **Корзина**: Нажмите "🛒 Корзина" для управления заказами
5. **Поиск**: Используйте команду `/search` для поиска товаров

### Для администраторов:

1. **Вход**: Отправьте `/admin` и введите пароль
2. **Управление**: Используйте админ-панель для управления товарами и заказами

## 🔧 API Методы

### MaxBotAPI Class

- `getMe()` - Получение информации о боте
- `sendMessage($chat_id, $text, $options)` - Отправка сообщения
- `editMessage($message_id, $text, $options)` - Редактирование сообщения
- `deleteMessage($message_id)` - Удаление сообщения
- `getUpdates($options)` - Получение обновлений
- `answerCallback($callback_id, $options)` - Ответ на callback

### Database Class

- `getCategories()` - Получение категорий товаров
- `getProductsByCategory($category_id)` - Получение товаров категории
- `searchProducts($query)` - Поиск товаров
- `addToCart($user_id, $product_id)` - Добавление в корзину
- `createOrder($user_id, $order_data)` - Создание заказа

## 🔐 Безопасность

- Все запросы проверяются на авторизацию через токен бота
- Вебхуки дополнительно проверяются по секретному ключу
- Пароли администраторов хэшируются
- SQL инъекции предотвращаются подготовленными запросами

## 📊 Мониторинг

- Логи вебхуков сохраняются в `webhook.log`
- Ошибки записываются в PHP error log
- Статистика доступна в админ-панели

## 🚨 Возможные проблемы

### Ошибка "Invalid access_token"
- Проверьте правильность токена в `config.php`
- Убедитесь, что токен активен в @MasterBot

### Ошибка подключения к БД
- Проверьте настройки в `config.php`
- Убедитесь, что MySQL сервер запущен

### Вебхук не работает
- Проверьте доступность URL вебхука
- Убедитесь в наличии SSL сертификата
- Проверьте правильность секретного ключа

## 📞 Поддержка
